1. Sobre o Skyes

O Skyes é um jogo gratuito atualmente disponibilizado em versão Demo/Teste, desenvolvido por Lkkziinnho.

Esta Política de Privacidade explica de forma transparente como as informações são tratadas durante a utilização do jogo.

2. Coleta de informações pessoais

Na versão atual do Skyes, o aplicativo não solicita diretamente informações pessoais como nome completo, endereço, número de telefone, documentos de identificação ou informações bancárias.

O jogo também não exige a criação de uma conta de usuário para ser utilizado.

3. Dados do jogo armazenados no dispositivo

Para permitir que o jogador continue seu progresso, o Skyes pode armazenar informações do jogo localmente no dispositivo.

Essas informações podem incluir:

  • progresso do jogo;
  • nível e experiência do personagem;
  • atributos e características do personagem;
  • posição do personagem;
  • itens e inventário;
  • equipamentos e runas;
  • configurações do jogo;
  • outros dados necessários para salvar e restaurar o progresso.

Esses dados são utilizados exclusivamente para o funcionamento do jogo e para manter o progresso do jogador.

4. Armazenamento local

Os dados de progresso do Skyes são armazenados localmente no dispositivo, conforme as funcionalidades disponíveis na versão atual do jogo.

O desenvolvedor não utiliza esses dados locais para vender informações pessoais ou para fins publicitários.

A limpeza dos dados do aplicativo ou a desinstalação do jogo poderá apagar o progresso armazenado localmente.

5. Publicidade

A versão atual Demo/Teste do Skyes não possui anúncios.

Não há, nesta versão, serviço de publicidade integrado ao aplicativo.

6. Compras e pagamentos

A versão atual do Skyes não possui compras dentro do aplicativo, sistema de pagamento ou assinatura.

O jogo é disponibilizado gratuitamente nesta versão Demo/Teste.

7. Contas e login

A versão atual do Skyes não exige criação de conta, cadastro ou login para jogar.

8. Compartilhamento de dados

O desenvolvedor não vende, aluga ou comercializa informações pessoais dos usuários.

Os dados de progresso armazenados localmente no dispositivo não são enviados pelo desenvolvedor para terceiros na versão atual do jogo.

Caso funcionalidades futuras introduzam serviços externos que alterem essa situação, esta Política de Privacidade será atualizada.

9. Serviços de terceiros

A versão atual do Skyes não utiliza serviços de terceiros destinados à publicidade, compras, pagamentos ou criação de contas de usuário.

Caso novos serviços sejam incorporados ao jogo no futuro, a política será revisada para refletir o tratamento de dados realizado por esses serviços.

10. Dados técnicos

A versão atual do jogo não solicita diretamente dados pessoais do usuário.

O sistema operacional ou a plataforma de distribuição do aplicativo pode processar determinadas informações técnicas necessárias para fornecer seus próprios serviços. Esse tratamento é realizado de acordo com as políticas correspondentes da plataforma.

11. Segurança

Adotamos medidas razoáveis para proteger as informações utilizadas pelo jogo.

Como os dados de progresso são armazenados localmente, a proteção desses dados também depende dos mecanismos de segurança do dispositivo utilizado pelo jogador.

12. Retenção e exclusão de dados

Os dados de progresso permanecem no dispositivo enquanto forem necessários para manter o funcionamento e o progresso do jogo.

O usuário pode excluir os dados locais utilizando as opções do sistema operacional, como limpar os dados do aplicativo ou desinstalar o Skyes.

A exclusão desses dados poderá resultar na perda do progresso salvo.

13. Privacidade de crianças

O Skyes não solicita intencionalmente informações pessoais de crianças.

Caso um responsável tenha alguma preocupação relacionada à privacidade de uma criança durante o uso do aplicativo, poderá entrar em contato conosco pelo e-mail informado nesta política.

14. Links externos

Caso o aplicativo venha a disponibilizar links para sites ou serviços externos, esses serviços poderão possuir suas próprias políticas de privacidade.

O desenvolvedor não é responsável pelas práticas de privacidade de serviços externos.

15. Alterações nesta Política de Privacidade

Esta Política de Privacidade poderá ser atualizada quando novas funcionalidades, serviços ou sistemas forem adicionados ao Skyes.

A data da última atualização será modificada sempre que esta política sofrer alterações relevantes.

Caso não concorde com os termos apresentados, o usuário poderá deixar de utilizar o aplicativo e removê-lo do dispositivo.
